# 🚗 Autonomous Lane Detection

A deep learning based lane detection system built with PyTorch and a lightweight U-Net architecture, trained on the TuSimple dataset.

## ⚙️ Setup

### 1. Clone / Download the project

```bash
cd ~/Desktop
```

### 2. Install dependencies

```bash
pip3 install -r requirements.txt
```

### 3. Download TuSimple Dataset

Download from: https://www.kaggle.com/datasets/manideep1108/tusimple

Extract and place at:
```
data/tusimple/train_set/
```

### 4. Preprocess the dataset

```bash
python3 preprocess_tusimple.py
```

This generates paired image/mask `.png` files in `data/tusimple/processed/`.

---

## 🏋️ Training

```bash
python3 train.py
```

- Trains for 20 epochs by default
- Saves best model to `checkpoints/model_best.pth`
- Saves training curves to `outputs/training_curves.png`
- Uses Apple MPS (Mac), CUDA (NVIDIA), or CPU automatically

**Expected results after 20 epochs:**

| Metric | Score |
|--------|-------|
| Val IoU | ~0.47 |
| Val Dice | ~0.63 |
| Val Loss | ~0.22 |

## 🧠 Model Architecture

**SimpleUNet** — a lightweight encoder-decoder network:

```
Input (3, 128, 256)
    │
    ├── Encoder Block 1  →  64 channels
    ├── Encoder Block 2  →  128 channels
    ├── Bottleneck       →  256 channels
    ├── Decoder Block 1  →  128 channels  (+ skip from enc2)
    ├── Decoder Block 2  →  64 channels   (+ skip from enc1)
    │
Output (1, 128, 256)  →  Lane probability map [0, 1]
```

Each block: `Conv2d → BatchNorm → ReLU → Conv2d → BatchNorm → ReLU`

## 📈 Metrics

| Metric | Formula | What it measures |
|--------|---------|-----------------|
| **IoU** | `TP / (TP + FP + FN)` | Overlap between prediction and ground truth |
| **Dice** | `2TP / (2TP + FP + FN)` | F1 score for segmentation |
| **Pixel Accuracy** | `(TP + TN) / Total` | Overall correct pixel classification |
| **Precision** | `TP / (TP + FP)` | How many predicted lanes are correct |
| **Recall** | `TP / (TP + FN)` | How many actual lanes were found |

## 🔄 Reset & Rerun

To clear all outputs and start fresh:

```bash
rm -rf outputs/*
```

Then rerun any script — all graphs, CSVs, and images will be regenerated automatically.
